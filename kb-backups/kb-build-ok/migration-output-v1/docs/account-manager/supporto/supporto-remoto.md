# Scarica ed installa il Software per il supporto remoto

Per scaricare il software è sufficiente seguire questi passaggi:

1. Naviga alla pagina [https://supporto.cloudfire.it/](https://supporto.cloudfire.it/)  
![](/kb-assets/b49123eea8-2022-09-12-17-12-16.png)
2. Premi sul pulsante **download**
3. Compila i **campi** mostrati nel seguente modo:
1.   Name: Usa valore specifico macchina e inserisci un nome significativo (Esempio: DomainController-LaTuaOrganizzazione)
2.   Organizzazione: Inserisci il nome della tua organizzazione. Per organizzare meglio le vostre sorgenti, consigliamo l’utilizzo di un unico nome per la vostra organizzazione.
4. Premi su **Download** e successivamente su **Fine**.
5. Partirà il download del nostro software  
![](/kb-assets/94833a6c7d-2022-09-12-17-12-27.png)
6. Premi su **Download** e successivamente su **Done**
7. Verrà avviato il download del software

Al termine del download esegui il file e informa il supporto tecnico di Cloudfire i dati che avete inserito durante la fase di configurazione.
