---
title: "Region MI2 - New features Openstack aaS"
---

Con il rilascio della nuova region MI2, per il servizio Openstack as a Service attivato in tale region viene messa a disposizione una **nuova console di gestione** e vengono aggiunte **funzionalità extra**, non presenti all’interno della region MI1.  
Vengono inoltre introdotte le **quote di servizio**, per motivi di sicurezza, che possono essere alzate in qualsiasi momento tramite richiesta al team di supporto di CloudFire.
