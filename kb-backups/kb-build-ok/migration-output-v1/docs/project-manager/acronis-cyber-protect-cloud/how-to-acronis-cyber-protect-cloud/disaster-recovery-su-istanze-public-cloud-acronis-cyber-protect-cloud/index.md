---
title: "Disaster Recovery su istanze Public Cloud - Acronis Cyber Protect Cloud"
---

Prima di procedere con la configurazione del servizio bisogna verificare di avere a disposizione la voce Disaster Recovery all’interno della dashboard di Acronis e selezionare la modalità di Disaster Recovery desiderata tra Cloud-Only, Site-to-Site, Multi-Site.  
Nel caso la voce non fosse presente, contattare il supporto tecnico di CloudFire.
