3CX è lo strumento attraverso cui puoi richiedere una licenza 3cx e/o deployare e migrare un Centralino 3CX in Cloud utilizzando uno ambiente cloud ad hoc. Aggiungendo e gestendo il servizio 3CX disponi di una o più istanze: un ambiente Cloud sempre pronto ed idoneo ad ospitare il centralino 3CX e il suo carico di risorse.
