Questa guida mostra i passaggi per poter impostare un limite di utilizzo dello spazio di archiviazione in cloud ad un utente sul servizio Backup Smart.

# Limitare utilizzo dello storage

Per impostare un limite è sufficiente seguire i seguenti passaggi:

1. Effettua il login al portale del servizio presso [Backup Smart - Login](https://backup.cloudfire.it/login)
2. Nel menù posto nella parte sinistra dello schermo, premere su **Manage**  
![](./attachments/Backup%20Smart%20-%20Limite%20storage%20-%201.png)
3. Premere sulla voce Users e poi premere sull’utenza alla quale si vuole limitare l’utilizzo di spazio di archiviazione in cloud  
![](./attachments/Backup%20Smart%20-%20Limite%20storage%20-%202.png)
4. Nella finestra a comparsa, scorrere fino in fondo e modificare le impostazioni relative allo Backup storage in cloud.  
Premere su **Done** in entrambe le finestre per salvare le modifiche apportate.  
![](./attachments/Backup%20Smart%20-%20Limite%20storage%20-%203.png)
