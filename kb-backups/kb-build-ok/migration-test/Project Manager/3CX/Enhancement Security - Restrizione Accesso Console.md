Per incrementare la sicurezza è possibile restringere l'accesso alla Console da specifici IP o Subnet:  
  

- Accedere alla console
- Admin > Advanced > Console Restriction
- aggiungere gli ip consentiti
- cliccare save

> [!NOTE]
> Prima di salvare controllare che sia presente il messaggio:  
> Your current IP address is allowed: “il tuo IP“ (unicast)
