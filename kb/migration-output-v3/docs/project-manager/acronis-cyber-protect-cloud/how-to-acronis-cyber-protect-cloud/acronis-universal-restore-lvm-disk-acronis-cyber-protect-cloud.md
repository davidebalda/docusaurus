Per ripristinare via **Acronis UR** una macchina con partitioning LVM seguire i seguenti passaggi dopo aver bootato via UR.

##### *Disclaimer: La seguente guida presuppone che l’utente conosca già come utilizzare l’UR. Di conseguenza si salteranno alcuni passaggi.*  
  
1\. click su Register **Manage this machine locally**.

![](/kb-assets/115574fc2b-image-20211123-112759.png)

  
2\. Successivamente cambiare la rappresentazione dei dischi da windows a unix

![](/kb-assets/d11e44c4f3-image-20211123-113046.png)

![](/kb-assets/771b239ffb-image-20211123-113115.png)

3\. Selezionare il backup da recuperare e selezionare tutte le partizioni

![](/kb-assets/293641fcd6-image-20211123-132529.png)

4\. A questo punto selezionare la seguente voce, dopo aver dato l’ok nell’immagine precedente:  

![](/kb-assets/bb8f328c82-image-20211123-141730.png)

5\. Proseguire quindi con il restore.  

p.s. il seguente procedimento è stato testato con le versione 15 e 16 di UR.
