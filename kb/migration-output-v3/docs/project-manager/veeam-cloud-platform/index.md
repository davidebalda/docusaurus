Veeam Cloud Platform è la soluzione ideale per modernizzare la rigidità di Backup e Disaster Recovery. Ti permette di accedere in modalità as a service a Veeam Cloud Connect e Veeam Availability Console e, da un unico ambiente integrato richiedere le licenze di qualsiasi edizione, effettuare backup e replicare off site il backup dei tuoi Server, VM e Workstation e di ripristinarli velocemente e definire un piano di disaster recovery con il software di backup leader al mondo.
