## Accesso da web

Indirizzo per amministratori: [mailadmin.cloudfire.it](http://mailadmin.cloudfire.it)

Indirizzo per utilizzo webmail: [mail.cloudfire.it](http://mail.cloudfire.it)

N.B. che sia [mail.cloudfire.it](http://mail.cloudfire.it) non seguita da una porta specifica es.: [mail.cloudfire.it](http://mail.cloudfire.it):9071

##   
Parametri configurazione POP/IMAP

### POP

Server posta in arrivo: [mail.cloudfire.it](http://mail.cloudfire.it)

Server posta in uscita: [mail.cloudfire.it](http://mail.cloudfire.it)

Autenticazione SMTP posta in uscita: abilitata, stesse credenziali di posta in arrivo

Posta in entrata: porta 995 auth SSL

Posta in uscita: porta 465 auth SSL

### IMAP

Server posta in arrivo: [mail.cloudfire.it](http://mail.cloudfire.it)

Server posta in uscita: [mail.cloudfire.it](http://mail.cloudfire.it)

Autenticazione SMTP posta in uscita: abilitata, stesse credenziali di posta in arrivo

Posta in entrata: porta 993 auth SSL

Posta in uscita: porta 465 auth SSL

### EXCHANGE ACTIVE SYNC

Server posta in arrivo: [eas.cloudfire.it](http://mail.cloudfire.it)

Server posta in uscita: [eas.cloudfire.it](http://mail.cloudfire.it)
