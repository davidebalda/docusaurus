---
title: "Region MI2 - Tipologia Scalable Storage"
---

Con la region MI2 viene introdotta la possibilità di scegliere tra **volumi classici e criptati** in fase di creazione dell’istanza o del volume.

![image-20250716-101633.png](/kb-assets/69b37614d5-image-20250716-101633.png)

:::info
I volumi criptati offrono una maggiore sicurezza del dato, richiedendo però più tempo in fase di creazione rispetto a quelli non criptati.
:::
