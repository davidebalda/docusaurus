## Introduzione

Questo sotto-menù permette la creazione di utenti e gruppi di utenti a cui assegnare permessi di accesso al portale di gestione del Cloud PBX.

## Descrizione delle sezioni

### User Roles

In questo sotto-menù è possibile creare un insieme di regole personalizzate che poi verranno assegnate ai vari utenti. Cliccando sul tasto ![](/kb-assets/dd71bb98cb-image2019-4-10-15-55-11.png)

 è possibile creare un nuovo nuovo insieme di regole specificando quali sezioni del portale Tenant saranno visibili.

### Tenant User

In questo sotto-menù è possibile gestire i vari utenti ed applicare ad ognuno di essi le regole create allo step 1.
