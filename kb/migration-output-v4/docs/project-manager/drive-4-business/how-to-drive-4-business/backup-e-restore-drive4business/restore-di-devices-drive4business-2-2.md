# Come eseguire il Restore di un Dispositivo

Per eseguire il restore di un dispositivo è sufficiente seguire i seguenti passaggi:

1. Effettua il Login al Client sul tuo dispositivo, inserisci le tue credenziali D4B. Premi il bottone **Log In** per accedere.  
![](/kb-assets/c531414a35-d4b-backup-e-restore-device-1.png)
2. Il Client Drive4Business permette di visualizzare i file e le cartelle sincronizzate sul portale Web e modificare le impostazioni del proprio D4B.  
Premi sul pulsante **Menù** posto in alto a destra nella finestra.  
![](/kb-assets/84eb0f131a-d4b-backup-e-restore-device-2.png)
3. Premi il pulsante corrispondente alla voce **Backup Manager** nel menù a comparsa.  
![](/kb-assets/ded3213846-d4b-backup-e-restore-device-3.png)
4. Dal pannello **Backup Manager** è possibile schedulare i Backup del dispositivo, selezionare le cartelle desiderate per i backup e creare snapshot.  
Premi su **Backup settings** per andare a schedulare i backup e selezionare le cartelle desiderate.  
![](/kb-assets/00538d18f0-d4b-backup-e-restore-device-6.png)
5. Imposta le tue preferenze per automatizzare il processo di Backup quando non utilizzi il dispositivo, così da salvare sempre i tuoi lavori.  
Vai sulla voce **Scheduling** e configura le impostazioni come desideri.  
![](/kb-assets/afc9601c50-d4b-backup-e-restore-device-7.png)
6. Successivamente spostati sulla voce **Folders** per andare a selezionare le cartelle che desideri vengano backuppate.  
Seleziona le cartelle e le sottocartelle spuntando il riguardo in corrispondenza di esse. Prosegui premendo **Apply**.  
Le cartelle selezionate verrano visualizzate nella sezione Folders.  
![](/kb-assets/b86da45615-d4b-backup-e-restore-device-9.png)
7. Premi su **Take a Snapshot** per creare un immagine istantanea del dispositivo allo stato attuale.  
![](/kb-assets/0dbbb2c7dc-d4b-backup-e-restore-device-4.png)
8. Associa un **Nome** allo Snapshot e prosegui premendo su **Commit**.  
![](/kb-assets/3b4600a026-d4b-backup-e-restore-device-5.png)
9. Premi su **Start Now** per avviare un Backup delle cartelle.  
![](/kb-assets/0acb542720-d4b-backup-e-restore-device-11.png)
10. Per verificare che il restore funzioni correttamente, elimina qualche file dalle cartelle che hai selezionato per il backup.  
(Es. se hai selezionato la cartella Desktop elimina qualche file dal Desktop).  
![](/kb-assets/3aafa29013-d4b-backup-e-restore-device-10.png)
11. Premi sul pulsante **Restore** nella finestra di dialogo di Backup Manager.  
![](/kb-assets/8043a8d2ed-d4b-backup-e-restore-device-12.png)
12. Premi su **Restore** per andare a recuperare i file eliminati dallo snapshot eseguito nei passaggi precedenti.  
![](/kb-assets/3b39de756c-d4b-backup-e-restore-device-13.png)
13. Seleziona il Dispositivo da ripristinare, il backup dal quale reperire i file mancanti e lo snapshot del restore.  
Premi **Next**.  
![](/kb-assets/f24cfa3304-d4b-backup-e-restore-device-14.png)
14. Seleziona la cartella da ripristinare e premi **Continue**.  
![](/kb-assets/225e2733e2-d4b-backup-e-restore-device-15.png)
15. Seleziona la destinazione per i file da ripristinare e l’azione da eseguire in caso di ripristino di un file già esistente.  
Prosegui premendo il pulsante **Commit**.  
![](/kb-assets/6a637a82d1-d4b-backup-e-restore-device-16.png)
16. Attendi il termine dei **Processi** del restore. Una volta terminati, i file o le cartelle persi/eliminati saranno stati ripristinati nella loro locazione originale o nella directory selezionata nel passaggio n15.  
![](/kb-assets/6212b3959e-d4b-backup-e-restore-device-17.png)
