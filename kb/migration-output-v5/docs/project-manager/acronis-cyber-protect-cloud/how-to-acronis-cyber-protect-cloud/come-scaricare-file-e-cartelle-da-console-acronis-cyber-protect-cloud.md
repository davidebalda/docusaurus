### Introduzione {#introduzione}

Quanto riportato di seguito, è considerato il metodo migliore per scaricare i file dalla console Backup Smart.  
Tuttavia, è presente un altro metodo che prevede, però, una limitazione sulle dimensioni dei file (massimo 100MB) che è possibile recuperare.  
Questa guida spiega come ripristinare i file protetti da Acronis, direttamente dal pannello di controllo del prodotto senza nessuna limitazione sulle dimensioni.

##    {#section}
Scaricare i file

  
Per scaricare i file senza nessuna limitazione sulle dimensioni, è sufficiente seguire i seguenti passaggi:

1. Effettua il **Login** al pannello di controllo del servizio con le credenziali che ti sono state fornite all’attivazione del prodotto
2. Una volta entrati, premi sulla voce **Devices** dal menù laterale posto a sinistra della schermata.  
Dopodiché premi sul dispositivo dal quale desideri scaricare i file e/o le cartelle.  
![](/kb-assets/6fbb4664e7-backup-smart-scaricare-file-1.png)
3. Dal menù a comparsa laterale posto a destra della schermata premi sulla voce **Ricovery**  
![](/kb-assets/487dc18801-backup-smart-scaricare-file-2.png)
4. Al suo interno vengono mostrati tutti i recenti backup eseguiti sulla macchina.  
Premi sul collegamento **More ways to recover**  
![](/kb-assets/43a4cfa87d-backup-smart-scaricare-file-3.png)
5. Premi sulla voce **Download files**.  
![](/kb-assets/71a1479392-backup-smart-scaricare-file-4.png)
  
Nella nuova finestra aperta, è possibile navigare i file presenti sulla repository dei backup e scaricare direttamente quelli interessati.
