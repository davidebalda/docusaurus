## Introduzione {#introduzione}

In questo sotto-menù è possibile gestire le funzionalità visibili e modificabili nel **portale extension** di ogni singola extension.

Il plan di **default**  che troverete ha tutte le funzionalità **abilitate**.

## Guida passo-passo {#guida-passo-passo}

Qui vi illustreremo come modificare il plan di **default** e come creare altri **plan.**

- Cliccando sul bottone![](/kb-assets/9bedaa0500-image2019-4-4-9-25-24.png)
 di fianco al plan di default è possibile abilitare o disabilitare le funzionalità disponibili nel **Portale extension** di ogni singola extension. Disabilitando una funzionalità non verrà proprio visualizzata nel menù "**Extension Settings**" del portale extension.
- Per creare un nuovo **Plan** cliccare su “**Add Plan**”, inserire un nome univoco, e attivare le funzionalità che preferite.

:::info
I **plan** creati verranno assegnati ad ogni extension in fase di creazione delle stesse:
Per info → [Extension](../service-2-2/extension-2-2.md)
:::
