Questa pagina definisce i passaggi da seguire per la gestione delle impostazioni del servizio Veeam Cloud Platform tra cui:

- **Impostazione Region predefinita** permette di selezionare la region visualizzata in modo predefinito all’accesso su Veeam Cloud Platform.
- **Trasferimento servizi** permette di trasferire un servizio all'interno di un altro Progetto dove questo non sia già stato attivato.

## Accedi alla sezione Impostazioni Veeam Cloud Platform {#accedi-alla-sezione-impostazioni-veeam-cloud-platform}

1. Accedi al servizio **Veeam Cloud Platform**. Non sai come fare? Segui la nostra [**guida**](index.md#accedi-al-servizio-veeam-cloud-platform)**.**
2. Seleziona la voce **Impostazioni** dalle tab in alto.

![Screenshot 2024-05-14 at 13.17.43.png](/kb-assets/110f1a2505-screenshot-2024-05-14-at-13-17-43.png)

### Imposta e modifica Region predefinita {#imposta-e-modifica-region-predefinita}

Definendo la Region Predefinita in questa sezione imposti come visualizzazione di default la region scelta. Per farlo puoi seguire i seguenti passaggi:

1. Accedi alla sezione **Impostazioni**;
2. Premi sul bottone Modifica nella sezione **Region Predefinita**;
3. Raggiungi la sezione **Region predefinita**
4. Seleziona la **Region predefinita** tra le voci disponibili nel menù a tendina;
5. **Conferma** la scelta premendo sul bottone verde.

![](/kb-assets/b15ff7a5f0-image-20230322-085626.png)

:::note
Potrai cambiare modello di pagamento anche in seguito.
:::

### Trasferisci Veeam Cloud Platform tra Progetti {#trasferisci-veeam-cloud-platform-tra-progetti}

Il **trasferimento** di un servizio tra due differenti progetti è l’attività che permette di migrare configurazioni ed informazioni del servizio da un progetto di origine ad un progetto di destinazione, mantenendo intatto dati e attività al suo interno.

Per effettuare il trasferimento di Veeam Cloud Platform tra progetti ti consigliamo di seguire questa [**guida**](https://cloudfireit.atlassian.net/l/cp/pvFoCac1).
