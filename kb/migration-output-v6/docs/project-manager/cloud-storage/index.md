![](/kb-assets/224e535a4d-cloud-storage-horizontal-logo.png)

Ideale per chi ha la necessità avere uno storage sicuro, affidabile e flessibile per archiviazione a lungo termine o per distribuire qualsiasi tipologia di file ai tuoi clienti. Il sistema Object Storage memorizza i tuoi dati in più copie, su diversi dischi e su diversi server garantendo così sicurezza e prestazioni.
