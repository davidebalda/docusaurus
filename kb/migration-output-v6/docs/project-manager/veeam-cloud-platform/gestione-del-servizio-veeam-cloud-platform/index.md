## Attiva le funzionalità di Veeam Cloud Platform {#attiva-le-funzionalita-di-veeam-cloud-platform}

Per attivare le funzionalità di Veeam Cloud Platform è sufficiente seguire i seguenti passaggi:

1. Accedi al Progetto nel quale vuoi attivare il servizio e seleziona la voce **Veeam Cloud Platform** nel menu di navigazione;
2. Premi sulla voce di menù laterale **Cloud Connect** se è la prima volta che attivi qualsiasi funzionalità di Veeam Cloud Platform;
3. Premi sulle voci di menù laterali oppure i bottoni **Scopri di più** in corrispondenza delle Card in base alla tua esigenza, se hai già attivato Cloud Connect.
