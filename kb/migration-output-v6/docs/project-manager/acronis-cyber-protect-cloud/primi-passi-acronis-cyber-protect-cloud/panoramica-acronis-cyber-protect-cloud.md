## Panoramica {#panoramica}

Accettando i termini, puoi decidere quali Agent scaricare per utilizzare il servizio Acronis Cyber Protect Cloud.

Sono disponibili diversi client, da scegliere in base al sistema operativo e entità della **macchina/servizio.** Eccone la panoramica:

- Workstation: Windows 8,10 e Linux Desktop
- Website
- Virtual Machine: Vmware, Hyper-v, KVM, AWS, Google Cloud, Azure
- Server fisici: Windows e Linux
- Office 365 e Microsoft Teams
- Mobile: Android/ IOS
- Hosting Server
- Google Workspace

:::info
In caso di installazione diretta sul S.O. interessato, i pacchetti sono degli eseguibili standard.
:::

Nota bene:

- In caso di utilizzo del **agent per i virtualizzatori** è necessario scaricare l'eseguibile Windows ed installarlo su una macchina di controllo. Durante l’installazione di questi ultimi verranno chieste le credenziali di accesso al virtualizzatore del cliente.
- Nel caso di installazione degli **agent specifici per il backup granulare SQL o Exchange**, verranno richieste le credenziali di un utente con permessi sufficientemente elevati per il loro management. Inoltre durante l’installazione sono richieste le credenziali relative all’utenza backup: indirizzo e-mail di registrazione e password impostata dal cliente nel portale di gestione Cortex.
- Sono consigliati gli agent completi nel caso di Windows: in alto a destra, premi sull’icona del profilo, e successivamente premi su "Downloads".

Una volta installato l’agent sul target di interesse puoi gestire i backup dalla console web dai seguenti URL in base alla region scelta:

- URL - Region Acronis-Eu2 - Francoforte, Germania: [eu2.backup.cloudfire.it](http://eu2.backup.cloudfire.it)
- URL - Region Acronis-Eu8 - Francoforte, Germania: [eu8.backup.cloudfire.it](http://eu8.backup.cloudfire.it)
- URL - Region Acronis-It01 - Roma, Italia: [it01.backup.cloudfire.it](http://it01.backup.cloudfire.it) ( in sostituzione a URL:  [**backup.cloudfire.it**](http://backup.cloudfire.it/) )

## Operazioni principali disponibili {#operazioni-principali-disponibili}

All’interno della dashboard troverai sulla sinistra un menù con le voci principali quali:

- **Monitoring**: comprende tutte le funzionalità del monitoraggio e funge da panoramica del servizio quale Overview, Allerts, Activities; Threat feed.
- **Device**: è la sezione do tutto ciò che riguarda i device, le macchine con gli agent installati, le macchine non gestite, e la mappa della protezione dei dati.
- **Management**: racchiude tutte le funzionalità legate al management operativo del servizio: piani di protezione, backup scanning, backup replication etc.
- **Disaster Recovery**: comprende tutte le funzionalità legate ai piani di disaster Recovery.
- **Protection**: comprende tutte le funzionalità legate alla parte di protection e security: antimal-ware, quanrantene, white list.
- **Software Management**: comprende tutte le funzionalità legate a patch di sicurezza, vulnerabilità e software inventory.
- **Backup storage**: racchiude l’elenco degli storage disponibili su cui è possibile salvare una copia dei backup.
- **Report**: comprende il report e le analisi dei backup e degli agent installati
- **Setting**: comprende le impostazioni varie.
